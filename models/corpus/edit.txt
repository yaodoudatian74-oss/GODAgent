冒頭 に タイトル の テロップ を 入れる 。
場面 の 変わり目 に フェード の 切り替え を 入れる 。
重要 な 言葉 に 強調 の テロップ を 重ねる 。
明るさ と 色味 を 整えて 見やすく する 。
背景 に 落ち着いた BGM を small 音量 で 流す 。
聞き取り やすい ように 音量 を そろえる 。
最後 に ロゴ と 締め の テロップ を 入れる 。
長い 間 を 詰めて テンポ を 上げる 。
見どころ を 先頭 に 持ってくる 構成 に する 。
字幕 を 付けて 内容 を 分かり やすく する 。
効果 音 を 要所 に 加えて メリハリ を つける 。
