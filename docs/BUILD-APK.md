# Building the Android APK

GODAgent ships an Android app: the **standalone (serverless) web build** wrapped
in a Capacitor WebView, so it runs **fully offline** — no server, data in
`localStorage`, the computer rendered as a real in‑app WebView of the bundled
fixture pages.

## The APK comes from CI

The signed APK is built by **GitHub Actions**
(`.github/workflows/android-apk.yml`) and attached to a **GitHub Release**.

> The environment this repo was authored in could not build the APK locally:
> Google's Android SDK host (`dl.google.com` / `maven.google.com`) is firewalled
> there, so `aapt2` / platform tools are unreachable. GitHub's runners can reach
> them, so the APK is built there with the official toolchain.

### Trigger a build

Push a version tag (the workflow runs on `v*` tags), or run it manually:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Then watch **Actions → Build Android APK & Release**. When it finishes, the
Release `v0.1.0` has **`GODAgent.apk`** attached (also downloadable as the
`GODAgent-apk` build artifact).

If Actions is disabled on the repo, enable it: **Settings → Actions → General →
Allow all actions**, then re‑push the tag (or use **Run workflow**).

## Build it locally (if you have the Android SDK)

Requires Node 20+, JDK 17, and the Android SDK (`ANDROID_HOME`, build‑tools +
platform 34):

```bash
scripts/build-apk.sh        # → ./GODAgent.apk
```

What it does: builds the standalone web bundle → `npx cap sync android` →
`./gradlew assembleRelease` → signs + aligns with `apksigner` → verifies.

## Install on a phone

1. Download `GODAgent.apk` to an Android device.
2. Open it; allow **install from unknown sources** when prompted.
3. Tap **Install** on the Android screen, then open **GODAgent**.

> The install dialog is shown by Android itself — a web page can't install an APK
> or skip that screen. iPhone cannot install APKs.

## What's inside

- `web/capacitor.config.ts` — Capacitor config (`webDir: dist-standalone`).
- `web/android/` — the committed native project (Gradle, wrapper, manifest).
  Generated assets (`assets/public`, the Cordova plugin project) are gitignored
  and regenerated by `cap sync` during the build.
- `web/src/standalone/backend.ts` — the in‑browser backend that makes the app
  work with no server.
